# Enable a formula

Enable `$ARGUMENTS` in the `elioseverojunior/intel` tap. Formulae are
generated by `scripts/tap/render.py`; never hand-edit a Formula file or its
bottle block.

1. **Decide the kind.**
   - `generated`: core's formula builds on Intel unchanged. Nothing else to
     write.
   - `patched`: core removed it, disabled it, gated it with
     `depends_on arch: :arm64`, or it fails to build on Intel. It needs a
     `base` core commit and `patches/<name>.patch`.
   - Report why the formula is not usable on Intel before changing anything.
2. **Add the entry to `enabled.toml`.**

   ```toml
   [formula.<name>]
   kind = "generated"

   [formula.<other>]
   kind = "patched"
   base = "<40-character core commit SHA>"
   ```

   For a formula removed from core, `base` is the last commit before the
   deletion:

   ```bash
   git -C "$(brew --repo homebrew/core)" log --diff-filter=D -1 \
     --format=%H^ -- Formula/<letter>/<name>.rb
   ```

   For a disabled or arm64-gated formula still in core, use the core commit
   you checked.
3. **Render.** Render reads `.cache/api/formula.json`: run
   `scripts/audit/fetch-api.sh` first when it is missing or stale (needs
   Python 3.11+, pinned via mise). `mise run render` (add
   `-- --core-commit <sha>` to pin core,
   `-- --print-order` to see the build order including tap dependencies).
4. **Patched only: write the patch.** Until it exists, render writes the
   formula unpatched from `base` and prints a notice. Edit the rendered
   `Formula/<shard>/<name>.rb` (`lib*` names go to `Formula/lib/`)
   minimally (remove arch gates, `disable!`,
   `deprecate!` added for Intel, or the build fix), then run
   `mise run render -- --make-patch <name>`. A patch may not change what the
   software does.
5. **Evidence for patched formulae** goes in the PR description: an upstream
   release or CI for `darwin-amd64`, or a successful build and `brew test` on
   the builder.
6. **Check drift:** `mise run drift` must pass, then `mise run lint` and
   `mise run test`.
7. **Verify on this Intel machine** (`brew style` on the specific formula,
   because the whole-tap run also scans the gitignored `actions-runner/`):

   ```bash
   brew style elioseverojunior/intel/<name>
   brew audit --strict --online --tap=elioseverojunior/intel
   brew install --build-from-source elioseverojunior/intel/<name>
   brew test elioseverojunior/intel/<name>
   ```

   Audit errors that core's own formula also has are accepted. If the build
   fails, report the error and stop; don't patch upstream source without
   asking.
8. **Commit** on a branch named `<name>`, signed (`git commit -S`), with no
   co-author trailer, using the subject `<name> <version> (new formula)`.
   Ask before pushing or opening a PR.
